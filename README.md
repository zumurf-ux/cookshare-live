# 오늘한입

사용자 모바일 앱과 운영자 웹 콘솔이 분리된 로컬 우선 실행 버전입니다.

## 실행

```powershell
npm run dev
```

- 사용자 앱: `http://127.0.0.1:4174/app`
- 운영자 콘솔: `http://127.0.0.1:4174/admin`

사용자 앱과 운영자 콘솔은 같은 출처의 브라우저 저장소를 사용하므로 게시물, 주문, 포인트, 신고 상태가 서로 반영됩니다.

## 디자인 규칙

- 배경 `#F2F2F7`, 표면 `#FFFFFF`, 본문 `#1C1C1E`, 강조 `#087BFF`
- 모든 그림자와 그라디언트 제거
- 흰색 카드, 1px 구분선, 10~18px 모서리 반경
- 이모티콘 대신 1.8px 선형 SVG 아이콘 사용
- 버튼 최소 높이 44px, 키보드 포커스와 모션 감소 설정 지원
