# 오늘한입

사용자 모바일 앱과 운영자 웹 콘솔이 분리된 로컬 우선 실행 버전입니다.

## 실행

```powershell
npm run dev
```

- 사용자 앱: `http://127.0.0.1:4174/app`
- 운영자 콘솔: `http://127.0.0.1:4174/admin`

## 외부 테스트

GitHub Pages 배포 후 저장소 기본 주소에서 사용자 앱과 운영자 콘솔을 선택할 수 있습니다.

- 진입 페이지: `https://zumurf-ux.github.io/cookshare-live/`
- 사용자 앱: `https://zumurf-ux.github.io/cookshare-live/outputs/cookshare-android-user-app.html`
- 운영자 콘솔: `https://zumurf-ux.github.io/cookshare-live/outputs/cookshare-operator-admin-web.html`

사용자 앱과 운영자 콘솔은 같은 출처의 브라우저 저장소를 사용하므로 게시물, 주문, 포인트, 신고 상태가 서로 반영됩니다.

## 구현 기능

- 사용자 앱: 피드 정렬·팔로우, 좋아요·저장·댓글, 레시피 검색·분류, 게시·수정·삭제, 임시 저장·이어쓰기, 숨김·복구
- 마켓: 상품 검색·상세, 장바구니 수량, 주문·상세·취소, 주문 상태 알림, 구매 포인트 적립
- 내 정보: 프로필 수정, 저장 목록, 주문 내역, 포인트 원장, 알림 읽음, 개인 설정
- 운영자 콘솔: 콘텐츠 공개 관리, 신고 처리, 주문 상태, 회원 검색·이용 상태, 포인트 조정, 운영자 초대, 시스템 정책, CSV 리포트
- 연동 정책: 점검 모드, 콘텐츠 등록 중지, 마켓 주문 중지, 회원 이용 제한이 사용자 앱에 즉시 반영됩니다.

## 디자인 규칙

- 배경 `#F2F2F7`, 표면 `#FFFFFF`, 본문 `#1C1C1E`, 강조 `#087BFF`
- 모든 그림자와 그라디언트 제거
- 흰색 카드, 1px 구분선, 10~18px 모서리 반경
- 이모티콘 대신 1.8px 선형 SVG 아이콘 사용
- 버튼 최소 높이 44px, 키보드 포커스와 모션 감소 설정 지원
